### ✨ Core Features

*   **Unified Dashboard:** Aggregate accounts from multiple banks into a single view.
*   **AI-Powered Insights:** Automatically categorize transactions, hunt down forgotten subscriptions, and detect anomalies.
*   **Bank API Security Scan:** An integrated module that checks the security of connected bank APIs.
*   **Freemium Model:** A clear monetization strategy with free and premium tiers.

### 🏁 How to Run Locally

> **Prerequisites:** Ensure you have `Docker` and `Docker Compose` installed.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/IT-diakon/diakon-bank.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd diakon-bank
    ```
3.  **Build and run all services:**
    ```bash
    docker-compose up --build
    ```
4.  Once all services are up, open `http://localhost:8080` in your browser.
